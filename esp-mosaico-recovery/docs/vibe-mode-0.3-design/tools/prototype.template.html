鼠标即手指：点按、上下拖动列表、从屏幕左边缘向右拖动返回。键盘 ↑ 是 AI 键，Esc 返回；下载页和输入页可直接打字。

按键与手势

AI立即返回上一页；在首页单击会提示“按两次切换”（最多 3 次）
AI ×2在首页打开快速切换，从当前应用的下一个开始
快速切换中单击 AI 选下一个；按住 AI 0.6 秒打开；点卡片也能打开；4 秒无操作自动关闭
按住 AI + 双击开关机键从正在运行的应用回到 Vibe Mode
左边缘右滑返回；页面跟随手指，拖不够远会弹回
长按 0.6 秒删除、忘记网络、关闭 Mosaico AI 等不可撤销操作
