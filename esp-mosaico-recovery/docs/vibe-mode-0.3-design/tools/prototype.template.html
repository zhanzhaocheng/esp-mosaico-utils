VIBE MODE 0.3

可交互原型：按设备 480×480 屏幕绘制，与设计文档中的页面图使用同一份布局数据。首页和 Ideas 页是一个横向分页：左右滑动或点底部圆点切换。商店、Wi‑Fi、USB 和 AI Agent 都是模拟，不连接真实服务；右侧“测试清单”列出了建议逐条验证的流程。

AI 键
Boot 键 开关机键
静态页面

鼠标即手指：点按、左右拖动翻页、上下拖动列表、从屏幕左边缘向右拖动返回。键盘 ↑ 是 AI 键，Esc 返回；下载页和输入页可直接打字。

按键与手势

左右滑动首页和 Ideas 页之间翻页：只有内容移动，状态栏和底部圆点不动；状态栏中间显示当前页 2 秒
AI子页：返回；Ideas 页：回首页；首页：息屏；弹窗：关闭。按下时屏幕边缘在按键下方亮起橙条并提示动作
Boot（键盘 ↓）按住：提示只有升级 Vibe Mode 才需要它；按住 Boot + 双击开关机键：进入更新模式
息屏首页按 AI 或无操作超时（Display 里设 1/3/5/10 分钟或永不）：Wi‑Fi 断开、背光调低；点屏幕、晃动或按键唤醒
自动旋转右侧“设备方向”模拟 IMU：界面跟随转正；输入时先不转
按住 AI + 双击开关机键从正在运行的 Idea 回到 Vibe Mode
左边缘右滑子页返回；页面跟随手指，拖不够远会弹回
列表行左滑Manage 和 Shared info 的行露出 Delete，删除后 4 秒内可 Undo
长按 3 秒删除 Idea、忘记 Wi‑Fi；中途松手就取消
按键触感按下键位即触发（不是抬起）；GO 可用时双击感，不可用时一下低沉的震动
